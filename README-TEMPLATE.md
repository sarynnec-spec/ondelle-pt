# Ondelle — Premium Aesthetics Clinic Template

Thank you for your purchase.

A production-ready Next.js 15 template for medical aesthetics clinics, med spas
and cosmetic dermatology practices, with GSAP scroll animation, Lenis smooth
scrolling and React Three Fiber.

## Quick start

```bash
npm install
npm run dev      # http://localhost:3000
```

## Rebrand in one file

Every piece of visible text lives in **`src/lib/content.ts`**. The `brand`
export at the top of it holds the name, tagline, phone, address, hours and
social links. Rewrite that file and the site becomes a different clinic — you
never need to open a component.

## Two things to do before you launch

1. **Turn on indexing.** The template ships `noindex` on purpose. Set the
   environment variable `SITE_INDEXAVEL=1` on your host when you are ready to
   be found.
2. **Replace the demo phone number.** It ships in the `555-0100–0199` range,
   reserved for fictional use in North America.
